NOVA — متجر إلكتروني تجريبي
=============================

التشغيل:
1) فك ضغط الملف ZIP.
2) افتح index.html في متصفح حديث (Chrome / Edge / Firefox).
3) لا يحتاج المشروع إلى تثبيت أو خادم محلي لعرض الواجهة الأساسية.

الملفات:
- index.html : بنية الصفحات وعناصر المتجر.
- styles.css : التصميم الداكن المتجاوب مع الجوال والكمبيوتر.
- app.js     : بيانات المنتجات وسلوك البحث والسلة والنوافذ والشات التجريبي.

التخصيص:
- لتعديل المنتجات: افتح app.js ثم عدّل CONFIG.products.
- لتغيير العملة: عدّل CONFIG.currency.
- لوضع رابط ديسكورد: عدّل CONFIG.discordInvite.
- الألوان الأساسية موجودة في أول styles.css داخل :root.

مهم — حدود النسخة:
هذه واجهة Front-End تجريبية وليست منصة إنتاج مكتملة:
- الحسابات غير آمنة ولا توجد قاعدة بيانات أو جلسات حقيقية.
- السلة والطلبات غير محفوظة في خادم.
- لوحة إدارة البائعين والمدير وتغيير الرتب تحتاج Backend وواجهات API وصلاحيات مفروضة من الخادم.
- PayPal ليس مفعلاً؛ يجب استخدام تكامل PayPal الرسمي من الخادم والتحقق من حالة الدفع هناك.
- رابط تسليم المنتجات يجب ألا يظهر إلا بعد التأكد من الدفع من جهة الخادم.
- الشات الحالي محلي تجريبي وليس اتصالاً مباشراً بالدعم.

قبل النشر:
أنشئ Backend (مثل Node.js/Express أو Django) وقاعدة بيانات، ومصادقة آمنة،
وتحققاً من صلاحيات Admin/Seller على الخادم، وحماية للمدخلات، وتكاملاً رسمياً للدفع،
وتخزيناً آمناً للروابط السرية. لا تضع أسرار PayPal أو مفاتيح API داخل JavaScript العام.
